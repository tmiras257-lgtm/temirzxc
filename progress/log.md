# Журнал формы

Ежедневные фото с одного ракурса → короткая оценка. Раз в неделю — сравнение по существу.
Фото в репозиторий **не сохраняются** — только цифры и заметки.

**Где живут данные:** фото формы и ежедневные оценки — в bulking (https://claude.ai/artifact/SUktvSDbYag2y7ijdK2K46),
вкладка «Прогресс» → «Форма». Активность (шаги, расход, сон, пульс) — карточка «Активность» в «Дневнике».

## Для Claude в новой сессии

1. Прочитай этот файл целиком перед оценкой нового фото.
   Данные bulking читаются инструментом ArtifactData (url выше), коллекция `data/users/me`:
   `meta` (профиль, вес), `m-YYYY-MM` (еда по дням, ручная активность в `days[дата].fit`),
   `body` (`list`: дата, id фото, талия, оценка `eval`), `fitbit` (`days[дата]`: steps, burn, sleep, rhr — пишет только Claude, страница лишь читает).
2. Добавь новую запись в «Дневник» (новые сверху): дата, вес, талия, оценка, заметки.
3. Каждые 7 дней — блок «Недельный итог»: тренд веса/талии и что изменилось визуально.
4. Не делай выводов о прогрессе по одному дню: разница день-к-дню — в основном вода, свет, еда.
5. Закоммить и запушь изменения в рабочую ветку.

## Протокол съёмки

- Одно место, один свет, телефон на таймере на одной высоте (≈ уровень пупка), одно расстояние.
- Утром, после туалета, до еды.
- Одна и та же одежда (шорты).
- Ракурсы: спереди, сбоку, сзади. Стойка расслабленная, живот не втягивать.

## Шкала оценки (каждый пункт 1–10)

- **Жир** — примерный диапазон % (визуально, ±3–4%).
- **Мышцы** — общий объём и плотность.
- **Пропорции** — плечи/талия, верх/низ.
- **Осанка** — таз, плечи, голова, сутулость.
- **Симметрия** — левая/правая сторона.
